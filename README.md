# جدار إنجازات نور ⭐

تطبيق ويب صغير ومهيّأ للجوال يساعد نور أثناء تعلّم استخدام الحمام خارج المنزل. بعد كل نجاح تختار نور ستيكرها، ثم تلمس مكانه على جدار الحمام الرقمي ليطير ويلتصق مع حركة احتفالية لطيفة.

[فتح التطبيق](https://noor-sticker-wall.vercel.app)

![أيقونة جدار إنجازات نور](public/app-icon.svg)

## المزايا

- 35 ستيكرًا أصليًا لشخصية نور، وعبارات تشجيعية، ورموز مرتبطة بالحمام.
- اختيار مكان الستيكر على الجدار بلمسة واحدة.
- أنيميشن للصق مع لمعات، اهتزاز خفيف، ونغمة احتفال اختيارية.
- حفظ تلقائي للجدار وعدّاد يومي على نفس الجهاز.
- إعدادات للكبار للتراجع، كتم الصوت، أو بدء جدار جديد.
- قابل للإضافة إلى الشاشة الرئيسية ويعمل دون اتصال بعد الزيارة الأولى.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npx next dev
```

## البناء

```bash
npx next build
```

## الخصوصية

لا توجد حسابات أو قاعدة بيانات. الإنجازات تُحفظ محليًا داخل المتصفح، لذلك لكل جهاز جدار مستقل.
